# brainwide-activity-analytics

Analytics pipeline for brain-wide Neuropixels data from the IBL Brain-Wide Map (2025 release). (Work in progress)

This is a university project for the Business Intelligence Systems course
(Systems Engineering, Wrocław University of Science and Technology, 2026/2027).

## Data

Data are accessed via the ONE API from the International Brain Laboratory public server.
They are provided by the International Brain Laboratory under CC-BY 4.0
and are not part of this repository.

If you use this project, please cite the original dataset:

> International Brain Laboratory et al. (2025). A brain-wide map of neural activity during complex behaviour. *Nature*, 645(8079), 177–191. https://doi.org/10.1038/s41586-025-09235-0
